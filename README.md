# Apuntes 2º DAM

Web de apuntes de 2º DAM (curso 2026-2027) hecha con [Zensical](https://zensical.org/) y publicada en GitHub Pages:

<https://alejandrodongar.github.io/2DAM/>

## Probar en local

```bash
uv sync
uv run zensical serve
```

La web queda en <http://localhost:8000/2DAM/>. Cada push a `main` la publica con GitHub Actions (`.github/workflows/docs.yml`).
